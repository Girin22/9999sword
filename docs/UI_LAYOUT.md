> 출처: 유저 목업 4장(405×720pt). 좌표는 ×2.667로 1080×1920 환산. 레퍼런스 이미지: `docs/reference/layout_ref.jpg` — 3/4 탑다운 세로 레인, 적이 상단에서 밀집해 내려오고 아군은 하단, 화면 맨 아래 카드형 액션 바. 구현은 `src/ui/layout.ts`에 아래 상수를 그대로 둔다.

## 하단 액션 바 — 3가지 상태

### A. 대장간 선택 (기본 상태, 슬라이드 1)
```
[          강 화          ]   x 299–773, y 1683–1845 (474×162)
```
- 버튼 위/안에 비용, 형상 게이지 5칸, 장인의 기운 10칸.
- 나 강림이 떠 있으면 막사 상태의 보급 3버튼이 [강림] 하나로 합쳐진다.

### B. 막사 선택 (슬라이드 2)
```
[기사 보급] [투검사 보급] [마검사 보급]        [회복]
 x 64–232    x 283–451     x 504–672         x 800–968   (각 168×162, y 1683–1845)
```
- 보급 버튼: 그 병종이 든 검 +N·특성 색·쇠함 N·적합도 색 테두리.
- 회복 버튼: 들어올 병사 초상+체력, "+N 더 위급", 침상 사용 중이면 잠김.

### C. 광산 선택 (슬라이드 3)
```
[1번]  [2번]  [3번]        [현재 생산속도 + 모두 내보내기]
 x 64   x 283  x 504        x 800–968
```
- 슬롯 1~3(아웃게임 해금 수만큼 활성, 나머지 잠금). 슬롯 탭 → 배치/교체할 유닛 선택(편성 유닛 중 전투 중인 유닛 목록이 슬롯 위에 작은 카드로 뜸).
- 우측 버튼: 생산 속도 표시 + **모두 내보내기**(광부 전원 전투 복귀).

## 레퍼런스 이미지에서 가져올 것 (`docs/reference/layout_ref.jpg`)
- 3/4 탑다운, 세로 한 레인. 길 중앙을 따라 적이 내려오고 양옆은 배경 소품.
- 적은 **떼**로 보여야 한다 — 잡몹 구간에 10~15마리가 화면 상단에 밀집.
- 아군은 하단에 3~6기, 큰 실루엣. 발사체·폭발이 중간 존에서 터진다.
- 하단 카드형 버튼: 큰 아이콘 + 숫자. 우리 게임에선 병종 보급 카드가 이 자리.
- 성벽/바리케이드 라인이 화면 가로를 가로지르는 구도 — 우리 성벽 존과 동일.

## 아웃게임 (목업 없음 — 임시)
- **타이틀**: 제목, [시작] / [이어서].
- **로비**: 상단 재화, 스테이지 카드 4개(S1~S3·무한: 식량 제한·레시피 목록·잠금), 하단 탭 [상점] [레시피].
- **편성**: 유닛 카드 그리드(식량·체력·방어·옵션), "식량 8 / 10", 광부 선택(최저 식량 기본), [출격].
- **결산**: 카드 1장 — 클리어/실패, 최고 +N, 질서/혼돈 횟수, 쇠한 검 합계, 드롭, 연대기, [로비로].
- **햄버거**: 배속, 사운드, 게임 초기화(경고 → 재확인), 크레딧.
