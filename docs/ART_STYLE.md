# 아트 스타일 · 캐릭터 리그 · 전투 연출 — 에셋 제작 지침

레퍼런스: `doodle_ref/` (5장). 공통점을 스타일 규칙으로 뽑았다. 에셋은 GPT 이미지 생성으로 만들고, 단순 UI는 SVG로 그린다.

## 1. 톤앤매너 (레퍼런스에서 뽑은 규칙)

- **외곽선**: 굵고 균일한 짙은 선(순검정보다 살짝 갈색/남색 섞인 검정). 선 끝이 둥글다. 내부 디테일 선은 외곽선보다 얇게 1단계.
- **실루엣**: 머리가 크고 몸이 작은 덩어리. 모서리는 전부 둥글게. 직선보다 볼록한 곡선.
- **눈·표정**: 점 눈 또는 흰자+큰 동공, 입은 작은 선. 세 획으로 감정.
- **색**: 채도 높은 파스텔 + 명도 높은 바탕. 캐릭터당 주색 1 + 보조색 1 + 살색. 그림자는 색을 어둡게 한 단 한 단계(그라데이션 없음). 살짝 거친 채색 텍스처 허용(크레용 느낌), 광원·하이라이트 없음.
- **바탕**: 종이/잔디 같은 밝은 단색 위에 옅은 텍스처.
- **하찮음**: 무기가 몸보다 크거나, 투구가 눈을 가리거나, 표정이 상황과 안 맞는다. 멋있게 그리지 않는다.
- **질서 = 파란 펜, 혼돈 = 빨간 펜** 원칙 유지: 특성 색·이펙트 색은 이 둘.

## 2. 캐릭터 리그 (아군 유닛 7종 · 데미갓 아바타)

캐릭터는 **파츠 분리**로 만든다. 2D 본 애니메이션은 없고, 코드가 파츠를 흔든다.

```
        [머리]           ← 머리+몸통+다리는 한 장 (body)
        [몸통]
   (팔) [    ] (팔)      ← 팔은 그리지 않는다. 양옆에 동그라미 2개 (hand_L, hand_R)
        [다리]           ← 다리는 body에 포함, 짧은 두 선/발
```

- **body 1장**: 머리·몸통·다리까지. 팔 없음. 정면 약간 3/4.
- **hand 동그라미 2개**: 몸 양옆에 붙는 원(살색 또는 장갑색, 외곽선 굵게). 코드가 위아래/앞뒤로 왔다갔다 흔들어 생동감을 낸다(걷기: 교대로 상하, 대기: 살짝 들썩).
- **무기는 hand에 붙는다**: 검·창·제식검·곡괭이 스프라이트의 피벗을 손잡이에 두고 hand_R에 부착. 공격 시 hand_R을 회전(휘두름)하거나 밀어냄(찌름). 방패는 hand_L에, 대검일 때는 body 뒤에 부착.
- **깃발(마검사)**: hand_L에 부착, 항상 든다. 깃발 천은 별도 레이어로 살짝 펄럭임(스케일 x 흔들기).
- **후광(아바타)**: 머리 위 별도 레이어, 삐뚤게 회전.
- **탈(몬스터)**: 몬스터는 리그 규칙에서 자유 — 전체를 한 장으로 그려도 된다(§4).

파츠 목록(유닛당): `body`, `hand`(공용 1장, 색만 틴트), 무기·방패·깃발은 공용 에셋. → **유닛 본체는 7장 + 손 1장**이면 끝난다.

## 3. 전투 연출 규칙 (유닛 AI = 이 움직임)

프레임 애니메이션 없음. 전부 코드 트윈.

| 상태 | 움직임 |
|---|---|
| 대기 | body가 1~2도 좌우로 까딱, hand 두 개가 살짝 위아래. 라인 보일 없음(리그로 대체) |
| 걷기 | body 상하 바운스 + 좌우 기울기 교대, hand 교대로 앞뒤 |
| **근접 공격 (기사)** | 상대와 만나면 **공격 속도 간격으로 상대 쪽으로 돌진해 살짝 포갰다가 튕겨 돌아온다**(부딪치는 속도감). 동시에 hand_R + 검이 크게 휘둘러짐(회전 −60° → +40°). 히트 순간 상대가 반대로 살짝 밀리고 흰 플래시. 대검은 느리게 크게, 쌍검은 빠르게 두 번 |
| **원거리 공격 (투검사)** | 부딪히지 않는다. 사거리 유지하며 **투척 → 옆으로 구르기(body 360° 회전 + 짧은 이동) → 투척 → 구르기** 반복. 투척은 hand_R을 앞으로 밀며 검기/창기 스프라이트 발사. 검 계열이면 초승달 검기, 창이면 직선 창기 |
| **마검사** | 깃발 들고 아군 밀집 지점 주변을 **천천히 돌아다닌다**(원 궤도). 일정 시간마다 깃발을 땅에 쿵 찍으면 원이 한 번 크게 펄스 → 범위 안 아군 버프 / 적 디버프 타격. 직접 공격은 안 함(제식검 공격력은 버프 강도로만) |
| 피격 | 반대 방향 8px 튕김 + 흰 플래시 1프레임 + 체력 바 흔들 |
| 기절 | body 옆으로 눕고 ×눈 오버레이 + 머리 위 별 회전. 검은 고철 스프라이트로 교체 |
| 기상 | 눕은 상태에서 튀어 오르며 고철을 든다 |
| 막사 귀환·재출격 | 걷기 그대로. 성벽 문 통과 시 잠깐 사라졌다 나옴 |
| 강림 | 하늘에서 파란 수직선 낙하 → body 1.3배 스케일 + 후광 등장 + 검 파란 틴트 |
| 몬스터 근접 | 기사와 같은 부딪침 규칙. 탈 쓴 몸이 통째로 돌진 |
| 거대 몬스터 | 4배 스케일 body, 걷기 바운스가 느리고 크며 착지마다 화면 흔들림. 성벽에 붙으면 성벽 쪽으로 몸을 기울여 들이받음(성벽 흔들림) |

**부딪침 규칙 공통**: 돌진 거리 = 상대까지 거리의 60%, 포개짐 8~12px, 돌아오는 시간은 공격 간격의 30%. 공속이 빠를수록 짧고 잦게, 느릴수록 길게 크게 — 무게 시스템이 눈에 보이는 지점.

## 4. HUD 가시화 규칙 (목업 반영)

- **장인의 기운**: 대장간 버튼(건물 카드)이 **황금색으로 아래에서 위로 차오른다**(10칸 = 10%씩). 가득 차면 버튼 테두리가 금빛으로 반짝 → 다음 클릭이 확정.
- **형상 게이지**: 강화 버튼 안쪽 5칸 작은 눈금.
- **보유 재료**: **광산 버튼(건물 카드)에 숫자로 표기**. 강화 비용은 강화 버튼에.
- 성벽 체력 바: 성벽 위 가로 전체. 거대 몬스터가 붙으면 빨간 깜빡임.

프롬프트 공통 접두: "flat 2D doodle sticker style, thick rounded dark outline, pastel saturated colors, no gradient, no lighting, slight crayon texture, chibi proportions, front 3/4 view, transparent background" + 레퍼런스 이미지 첨부.

### SVG로 직접 (코드/벡터)
- 버튼 프레임(둥근 사각, 손그림 테두리), 햄버거 아이콘, ×2 배속 토글, 체력 바·성벽 바·게이지 칸, 범위 원(점선), 아이콘(버프·디버프·쇠한 검·특성 색 점), 결산 카드 프레임, 로비 카드 프레임.
- 폰트: 손글씨 1(제목) + 고딕 1(수치).

### 사운드
- 가져오기: 전투 BGM, 로비 BGM, 타격음, 마법 타격음.
- 생성: 버튼 클릭, 망치, 강화 실패, 강림, 거대 몬스터 발소리, 성벽 피격, 웨이브 클리어, 구르기, 깃발 찍기.
